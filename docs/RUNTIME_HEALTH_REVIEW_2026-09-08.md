# 运行环境检查与修复入口优化

本轮仅修改代码，不执行 GPU 训练、评测或合成，不发布新 EXE。

## 变更

- 启动器用项目内 Node 实际加载 node-pty、运行 Vite 所属 esbuild；检查限时 10 秒，异常返回具体原因。模块入口文件存在不再等同于可用。
- 安装结束后复核环境，检查失败不显示完成、不迁移 EXE。状态页分别展示 WebUI 依赖与构建状态。
- 修复时复用已通过检查的组件及已有构建；重装损坏依赖后重新构建。项目源码更新仍执行锁文件安装与构建。
- 预检区分运行时缺失、项目入口缺失、自定义模型缺失、内置模型缺失和素材缺失。对应按钮分别进入环境修复说明、模型训练或素材准备。
- 设置页展示 Python、项目入口的文件存在状态，并给出具体修复说明。文件存在不作为 GPU 运算能力证明。

## 验证

完整发布检查通过：WebUI 99 项通过、1 项符号链接权限跳过；启动器 Pester 72 项通过、1 项完整产品运行时缺失跳过；终端桥 5 项、Sites 4 项通过。翻译检查、生产构建、构建来源一致性与 HTTP 冒烟通过。最后的 C# 小调整已另行复跑启动器检查。

新增覆盖：入口存在但 ABI 加载失败、模块加载卡死、中文及空格路径、运行时/模型/素材错误的恢复路由。

浏览器验证环境：`http://127.0.0.1:4173/?lang=zh`，Edge headless，1440 × 900。Browser plugin not available；按前端测试技能使用仓库 Playwright 与已安装的 Edge。最初临时端口不在服务允许来源中，改用项目标准端口后通过，未放宽服务来源限制。
