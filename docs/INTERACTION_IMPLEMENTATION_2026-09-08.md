| 成果交接 | 导出页优先展示播放器；工作区复用同一成果组件。区分合成/遮罩视频，显示实际时长、分辨率、大小、生成时间，支持打开文件夹、复制路径、关联日志。新生成记录独立保存参数与应用版本。其他格式和模型导出分区折叠。 |
| 紧凑布局与键盘 | 优先保留项目名称和主要操作；帮助文字、焦点轮廓与工具标签改善。弹窗支持 Tab 循环、Escape 关闭和焦点返回。 |

## 验证结果

- 隔离回归：107 项，106 通过、0 失败、1 跳过。跳过项为 Windows 拒绝创建测试用文件符号链接（EPERM）；目录链接拒绝测试正常通过。
- 新增验证包含正常停止语义、曲线去重与容量限制、跨侧人脸/源帧/原视频复制、原目标与成片恢复、素材变化后复核失效、暂存副本清理、生成记录持久化、非法路径与未登录写入拒绝、运行中任务阻止人物分配和恢复。
- 生产构建通过；中英文检查通过，未增加既有未翻译项（基线 212 项）。
- 浏览器实际检查：1280×720 与 800×720。训练模型 `interview-e2e-128`、CPU 和估算目标 1000 能带回配置；预检通过后取消，没有启动训练。
- 现有 SRC 67 张素材分析为一个候选组；整组选中 67 张、命名、跨侧去向提示、确认弹窗 Tab 循环、Escape 返回均正常。只复核并取消，没有更换真实项目素材。
- 现有 4 秒、1920×1080 成片完整播放到结束；成片/遮罩切换、生成参数、复制路径正常。打开文件夹按钮调用无报错；未对资源管理器窗口做视觉验收。
- 工作区复用成果组件并显示 SRC/DST 人物入口。浏览器错误/警告日志为空；检查的桌面和紧凑页面没有文档横向溢出，紧凑布局通过纵向滚动访问完整操作栏。
- 本机服务已更新并运行于 `http://127.0.0.1:4173/`。最终实际数据仍为 SRC 67 张、DST 62 张、merged 与 mask 各 100 帧；没有新增训练或重新导出任务。
