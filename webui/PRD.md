# DeepFaceLabSN 本地 Web 管理器 PRD

## 1. 产品定位

DeepFaceLabSN Web 管理器是运行在用户本机的工作台。它把已有的 DeepFaceLab 命令行流程组织成可观察、可交互、可恢复的任务，而不是在浏览器中复刻或执行 BAT 文件。

当前基线覆盖从导入素材到视频编码的完整流水线：SRC/DST 拆帧与切脸、aligned 浏览/清洗/维护、Web XSeg 标注、XSeg 训练与应用、多模型训练/合成/导出，以及 MP4、AVI、MOV 编码。

## 2. 目标

- 用户可以从已采纳的方案 1 工作台直接启动受支持任务。
- 页面展示真实进程、命令、PID、运行时长、输出、退出码与产物。
- 所有 CLI 问答都可以在内置终端中完成，键盘输入直达该任务的 ConPTY。
- 页面刷新后可以恢复任务列表、历史输出和仍由服务持有的活动会话。
- 常用 CLI 问答可以由参数向导提前生成，复杂场景仍可保留原始 CLI 交互。
- 用户可以在工作区管理器中导入素材、检查帧/人脸/模型/输出，并播放允许的结果视频。
- 页面显示 GPU、显存、温度、训练速度与预计完成时间。
- 训练控制不会依赖模拟按键或外部 OpenCV 窗口。
- 一个任务的日志、元数据、控制指令和预览图可在磁盘上审计。
- 安全边界清晰：仅本机监听、命令白名单、固定可执行文件、参数校验、资源锁。

## 3. 非目标

- 独立安装、没有可维护源码的闭源 EXE 本轮不接入、不嵌入，也不做自动化控制。
- 本轮不实现任意 BAT、任意可执行文件或任意 Shell 命令运行器。
- 本轮不迁移 TensorFlow 模型到 PyTorch。
- 本轮不实现远程访问、多用户、云端调度或账号系统。
- 本轮不改变已有 DFL 模型格式和训练算法。

## 4. 核心用户流程

### 4.1 启动任务

1. 用户在流水线或“新建任务”选择受支持任务。
2. 前端读取命令注册表显示说明、运行时和资源要求。
3. 服务校验工作区、输入文件和资源锁。
4. 服务创建任务目录、元数据和 ConPTY，然后返回任务 ID。
5. 终端自动切到新会话，持续显示真实输出。

### 4.2 回答 CLI 问题

1. 输出解析器识别常见 DFL 提示并把任务标记为“等待输入”。
2. 用户在终端输入答案或使用“默认 / 是 / 否”快捷回答。
3. 原始字符写入该任务的 PTY；输入作为脱敏事件记录。
4. 后续输出到达后任务恢复“运行中”。

### 4.3 控制 SAEHD 训练

- 保存：向训练控制文件追加 `save`。
- 备份：追加 `backup`。
- 刷新预览：追加 `preview`，Trainer 把最新预览写入任务目录。
- 安全停止：追加 `close`，Trainer 先保存模型再退出。
- 强制终止：仅作为显式高风险操作保留在 API；不放在主操作区。

### 4.4 刷新与恢复

- 浏览器刷新：重新获取任务列表，重连服务仍持有的 PTY，并补齐持久日志。
- 服务重启：读取磁盘任务元数据；先前活动任务标记为“连接已丢失”，不伪装为可控制。
- 已完成任务：可查看退出码、历史日志和预览产物。

### 4.5 参数向导与工作区

1. 用户选择任务后决定使用“引导模式”或“CLI 模式”。
2. 引导模式仅展示该命令注册的参数定义、默认值、范围和枚举。
3. 服务端再次校验参数并执行前置检查，客户端不能注入 argv 或路径。
4. 工作区页面独立展示 SRC/DST、模型和输出状态；进入该页面时自动收起终端，为素材管理留出空间。

### 4.6 Web 原生源码工具

- SRC/DST aligned 浏览器直接展示 JPG、源文件名、DFL 元数据、XSeg 多边形和已应用遮罩状态。
- 清洗操作先移动到 `workspace/.webui/quarantine`，可在 Web 中恢复，不直接删除。
- XSeg 编辑器直接读写 `SegIEPolys` 的 include/exclude 多边形，支持加点、闭合、拖动、撤销和保存。
- 合成向导把模式、遮罩、腐蚀/模糊、色彩转换、锐化、超分和降级参数送入 DFL 源码适配层，不启动 Merger 窗口。
- Trainer 预览、保存、备份和安全停止通过源码控制桥完成，不依赖外部窗口。
- 失败或失联任务可以在设置页使用原命令、模式和参数重新创建。

### 4.7 全工具工作台

- 数据审计把 `Sorter.py` 的质量判断转成可解释的清晰度、曝光、重复来源、DFL 元数据和姿态筛选；分析按页有界扫描且可遍历完整数据集，清洗只进入可恢复隔离区。
- 姿态图谱同时读取 SRC / DST，按各自数据集内的姿态占比计算匹配度，优先标记“DST 已覆盖但 SRC 缺失或偏少”的训练风险；单库数量与清晰度审查仍可切换使用。
- 提取复核按源帧显示真实 `source_rect`、landmarks 和对应 aligned 结果，明确标记漏提与多人脸帧；重新落点由固定 Extractor 命令接力。
- 合成复核只从固定工作区槽位读取 DST 原帧、merged 与 merged_mask，支持逐帧验收；GPU 参数实时重算继续使用固定 Merger 路径。
- 视频时间线使用浏览器原生流媒体和 Range 请求，不把视频整体读入内存；裁切、抽帧与降噪继续使用固定命令注册表。
- 元数据、PackedFaceset 与模型导出预检均为只读、有界分析；保存、恢复、打包、解包和 DFM 导出只接受固定命令 ID。

## 5. 命令范围

| 分组 | 数量 | 覆盖 |
| --- | ---: | --- |
| 素材提取 | 4 | SRC/DST 拆帧、S3FD 切脸 |
| aligned 数据集 | 18 | 排序、关键点检查、缩放、增强、打包/解包、文件名与元数据维护 |
| XSeg | 10 | 训练、自定义/内置模型应用、标签获取/移除、已应用遮罩移除 |
| 模型训练 | 5 | SAEHD、ME、Q384、Q512、XSeg |
| 模型应用 | 5 | SAEHD、AMP、ME、Q384、Q512 |
| 模型导出 | 4 | SAEHD、ME、Q384、Q512 DFM |
| 视频工具 | 3 | SRC/DST 裁切、DST 帧降噪 |
| 视频封装 | 4 | MP4、无损 MP4、AVI、无损 MOV |

共 53 条。命令的 Python、入口文件、工作目录和核心参数全部由服务固定；客户端不能上传可执行文件或自由参数数组。逐项命令 ID 与能力边界见 `CAPABILITY_MATRIX.md`。

## 6. 信息架构

- 保留方案 1：左侧导航、项目/GPU 顶栏、横向流程、当前流水线、训练面板、实时状态。
- 底部控制台升级为终端监视器：
  - 多任务标签与状态；
  - PID、时长、运行时和重连状态；
  - xterm 终端输出；
  - CLI 输入框和快捷回答；
  - 训练任务的保存、备份、刷新预览、安全停止；
  - 日志、命令和任务目录信息。
- 服务离线时明确显示“本地服务未连接”，不再用假日志冒充运行结果。
- 左侧“工作区”提供视频导入、素材计数、模型分组、输出播放与完成任务归档。
- 左侧 SRC/DST、XSeg、模型训练、模型应用、视频导出、工具与设置均为真实功能页，不再是占位入口。
- 顶栏与训练状态卡显示 NVIDIA 遥测；没有 NVIDIA 或 `nvidia-smi` 不可用时优雅降级。

## 7. 安全与可靠性要求

- HTTP 和 WebSocket 仅绑定 `127.0.0.1`。
- 拒绝非本机 Origin；所有写操作使用服务启动时生成的会话令牌。
- 只允许命令注册表中的 ID，禁止 Shell 字符串拼接。
- 路径必须经过规范化并保持在仓库或工作区允许范围内。
- 任务开始前取得资源锁；结束后在 `finally` 路径释放。
- 日志按任务写入 NDJSON；元数据使用原子替换保存。
- 训练“安全停止”必须走模型保存路径；强制终止必须明确区分。
- 输入长度、终端尺寸、请求体和日志缓存均有限制。

## 8. 外部窗口预留

服务定义 `ExternalWindowAdapter` 接口，未来可实现：

- 启动并跟踪外部窗口；
- 暴露窗口标题、句柄、进程和能力；
- 截图或画面流；
- 受控输入；
- 关闭与失联处理。

本轮仅为未来外部窗口整合提供禁用接口和能力声明，不捕获、不嵌入、不操控独立闭源 EXE。已有源码的 Trainer、Merger 和 XSeg 标注能力优先通过 Web 原生适配完成。

## 9. 验收标准

- `GET /api/health` 返回本地运行时、工作区和支持能力。
- 53 个命令能由注册表生成准确、无 Shell 的 executable/argv。
- SRC/DST aligned 浏览、可恢复隔离/恢复以及 XSeg 标注读写均操作真实 DFL JPG 数据。
- SAEHD 引导合成不弹出 Merger 窗口，能完成 merged、merged_mask 与最终视频闭环。
- 引导模式和 CLI 模式都经过同一套服务端参数白名单与前置检查。
- 启动任务后终端可实时输出并接受交互输入。
- 同一 GPU/模型资源冲突时，第二个任务被明确拒绝。
- 训练保存、备份、刷新预览、安全停止均进入 Trainer 的正式控制路径。
- 刷新页面后可恢复任务和日志；服务重启后旧活动任务显示为失联。
- 服务离线、输入缺失、非零退出和启动失败都有可读错误。
- 单元/集成测试、生产构建、Sites 兼容测试通过。
- 浏览器端到端覆盖刷新、参数向导、工作区、遥测与断线恢复；变更型套件额外覆盖 CLI 输入和 SAEHD 保存式停止。
- 1440px 桌面和 390px 移动端无关键遮挡，终端可用。
