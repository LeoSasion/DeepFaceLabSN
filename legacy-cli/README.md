# 传统 BAT 命令

这里集中保留 DeepFaceLabSN 的传统 BAT/EXE 命令，作为 WebUI 尚未覆盖场景的兼容入口。项目根目录的 `传统命令菜单.bat` 会启动本目录中的交互式 CLI 路由器。

## 使用方法

1. 从项目根目录双击 `传统命令菜单.bat`。
2. 用数字或字母选择视频、SRC、DST、XSeg、训练、模型应用、视频封装和其他工具分类。
3. 在分类页中选择命令；命令结束后按任意键返回路由器。

路由器只运行当前分类中枚举出的文件，不接受任意命令字符串。主菜单还提供以下入口：

- `R`：最近使用的传统命令。
- `G`：GPU 设置与 RG 工具。
- `W`：WebUI 管理器。
- `E`：旧 Explorer 展开/收缩菜单的兼容入口。

可从命令行执行 `传统命令菜单.bat --check` 进行只读自检，或执行 `传统命令菜单.bat --preview` 查看主菜单预览。

## Explorer 兼容菜单

旧版依赖隐藏属性实现的 Explorer 二级菜单仍然保留，但不再是默认入口。只有需要这种显示方式时，才从 CLI 主菜单按 `E`，再运行初始化；初始化仅调整 `legacy-cli` 内的文件可见性，不修改全局 Windows 设置。

传统 BAT 会通过自身所在目录定位项目根目录和 `_internal` 环境，不要求从特定工作目录启动。

WebUI Runtime 不会解析或执行这些 BAT；WebUI 使用固定命令注册表直接调用 Python/CLI。
